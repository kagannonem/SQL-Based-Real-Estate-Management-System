Real Estate Management System (REMS)
A robust, SQL-based backend application designed for efficient real estate data management, developed as the final project for MTM4692 – Applied SQL. This system streamlines the management of offices, agents, property listings, and client transactions.

Project Overview
This application provides a structured approach to managing real estate operations through a relational database. It utilizes SQLite for lightweight, portable storage and a FastAPI interface to expose CRUD (Create, Read, Update, Delete) functionality for core business entities.

Technical Stack
Database: SQLite

Language: Python 3.9

API Framework: FastAPI

Architecture: Data Access Object (DAO) pattern for modular interaction between the application logic and the database.

Database Schema
The system manages complex relationships between the following key entities:

Offices & Agents: Organizational hierarchy and personnel management.

Properties & Listings: Comprehensive tracking of inventory.

Clients & Viewings: Managing lead generation and scheduling.

Transactions: Finalizing sales and lease history.
